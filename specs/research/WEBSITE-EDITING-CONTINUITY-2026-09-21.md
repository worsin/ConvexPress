# Website editing continuity

The Website must keep editing while the desktop operator remains authorized, without turning an expired management session into independent authority. The existing controller issues fresh, scoped sessions and rechecks hierarchy/permissions. Reuse that path from the signed-in desktop; do not make the Website renew its own expired parent.

- The desktop starts a bounded loopback listener for the explicitly selected website. A random, memory-only ticket and exact public origin protect requests; bind to127.0.0.1 with an OS-selected port. No arbitrary RPC, browser-selected backend, cookies, persisted credentials or general controller tokens are exposed.
- A Website renewal request asks the owning desktop window for a new one-use handoff. The renderer reuses the controller broker with the original connection/environment, then invokes the existing site handoff mutation. The browser redeems that handoff against its configured site backend as before. Owner-window destruction, logout, expiry and explicit end close the listener. Limit connections, request bodies, outstanding requests and lifetime; reject wrong Host/Origin/ticket and obsolete responses.
- The Website scrubs bridge details from the initial fragment, retains them only in memory, and renews before the five-minute token ends. Compare authenticated principal and installation before replacing a token. Keep the same React subtree for a successful same-owner renewal. On refusal/expiry, drop authority and retain the prior recovery copy; a visible reconnect action retries through the same desktop channel in the existing tab.
- Browser local-network permission may be required. Surface denied/unavailable desktop connections rather than weakening browser policy. Chrome documents permission-gated loopback fetch in https://developer.chrome.com/blog/local-network-access . Test actual native launch and actual public-browser behavior; do not infer hosted-browser compatibility from local Node requests.
- Reload, desktop process restart and the eight-hour bridge ceiling require a new explicit launch; private saved drafts remain durable. These limits must be visible and must not silently discard dirty work. No claim of full HB1 until real renewal/reconnect/revocation/customer-denial and all-pack acceptance pass.

Acceptance: listener Host/Origin/ticket/body/concurrency/timeout/close tests; renderer scope and stale-callback tests; Website successful renewal preserves draft/history, failure/retry recovers in place, end cancels pending renewal; backend handoff still enforces role/site/customer boundaries; native plus Website live proof past the old deadline, preservation and cleanup.
