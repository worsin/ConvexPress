## 3. Conventions and gotchas (read before touching anything)

- **Packs never import `convex/react` or the generated `api`**; data comes through the surface `data` props and SDK hooks (`@/hooks`, `@/contexts`, `@/components`). Token classes only, `font-display` for headlines, Base UI only. `check:templates` enforces the first two.
- **Adding a surface**: file `packs/<id>/surfaces/<surface>.tsx` with a default export `({ data, variant, packId }: SurfaceProps<XSurfaceData>)`, import the data type from the Core surface, then `bun run sync:templates` (updates `template.json` and the admin mirror).
- **Do not run agents that share a parts file**; give each its own (`parts/extra-<group>.tsx`).
- **Admin dev renderer must run with `VITE_STANDALONE_CONTROL_PLANE=true`** (`packages/desktop/scripts/dev.mjs` sets it). Without it the app boots the single-site flow against the control plane and shows an error screen (`main.tsx` now renders one; there is no blank window any more).
- **Desktop CSP**: deployment origins are registered at runtime (`electron/deploymentOrigins.ts`, `security:*` IPC) and persisted; the policy applies to the app's own documents only (frames keep their own headers). Rebuild `dist-electron` with tsup after editing `electron/*` (do not use the `build:electron` script's `rm -rf`).
- **Fleet access from this Mac**: SSH tunnel `ssh -fN -D 17890 -L 147xx/148xx:192.168.1.246:47xx/48xx worsin@192.168.1.246`; admin keys `ssh worsin@192.168.1.246 cat ~/ConvexPress-Test-Fleet/credentials/site-{alpha,beta,gamma}.admin-key`; deploy `bunx convex deploy --url http://127.0.0.1:148x0 --admin-key … --yes` from `packages/backend`. Storefront processes must use the tunnel origins (`CONVEXPRESS_CONVEX_URL=http://127.0.0.1:148x0`).
- **Playwright against the Electron shell**: `waitFor()`/`click()` can stall on "waiting for navigation to finish" after actions that open external links; poll `isVisible()`, use `noWaitAfter`, `force` on Base UI menu items, and pre-seed `convexpress-deployment-origins.json` in throwaway profiles. Drivers: `output/playwright/shopping-experience/{author-site,shoot-storefront,probe-rail,electron-runner}.mjs`.
- **Browser etiquette**: headless Playwright or a throwaway-profile Electron for verification; never several browser-driving agents at once; do not kill processes on shared ports (4105 admin renderer, 4201/4203 storefronts, tunnel) without checking.
- **Reserved storefront routes** (`/help`, `/support`, `/shop`, `/products`, `/blog`, …) collide with page slugs; no admin warning yet (worth adding).
- **Auto-commits**: the repo commits every few minutes; check `git log --stat -3` before editing shared areas.
