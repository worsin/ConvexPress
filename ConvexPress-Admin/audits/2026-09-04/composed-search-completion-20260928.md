## Behavior and repair

Search previously skipped every custom composition, including its canonical children. Internal candidate text now includes only explicitly declared authored custom search fields and canonical child copy. At query time, current publication/access checks, membership and disabled-block projection precede exact version approval. Current pack treatment, conditions, child slots, authorized media and selected live resolver data determine actual searchable prose. Reference binding checks are shared with the Website renderer. A selected navigation resolver receives the full host definition context. URLs, IDs and private configuration are not text.

A `content.search` composition excludes data-dependent branches through the closed expression evaluator, avoiding recursive search. Its independent authored prose and authorized child slots remain searchable. Its result loop still renders on the actual Website. Remote data is not copied into stored candidate text. Canonical Library fields continue to require declared search descriptors and any necessary current-presentation projection; arbitrary string attributes are not indexed.

Revoking a required visible definition makes the document unavailable through the existing public projection contract; search likewise excludes its canonical body. Reapproval restores searchability without a page write or reindex. A first lifecycle harness assertion incorrectly expected another composition in that unavailable document to remain searchable; inspection of `service.ts` and `loadPublishedComposedRegistry` confirmed the existing whole-document approval policy, and the harness was corrected. This was not changed into a partial-publication policy.

Native acceptance then exposed E38: restoring the three-definition document failed twice at the actual backend's one-second CPU limit. Both attempted restores left document revision 3 intact; the saved revision's exact tree and definitions were independently checked. Repeated pure definition decoding/hashing dominated a local CPU profile. A private FIFO cache now retains only validated exact-input JSON and digest strings, bounded to 32 entries and 1 MiB of combined encoded input/output bytes. Every decode retains byte guards and expected-digest validation; every return has an independent object. No approvals, resource grants, sessions or authority are cached. The measured 400-registry workload fell from 1028 ms to125 ms. This is a local repeated-work benchmark, not a claimed server response latency.

After strict deployment, the same native restore succeeded as document revision 4, matching the original tree and definition snapshot exactly. The actual Website draft preview visibly rendered restored prose and children. The two pre-repair timeout console entries are retained in evidence; there were no new native errors after repair. The broad backend run also exposed an obsolete AI test assumption that Core has no block styles. Its assertion now checks the actual requirement: Journal's CTA treatment is unavailable after switching to Core, while the saved style remains preserved.
