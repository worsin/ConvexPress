# Operations pagination and live backup acceptance

The real Electron Operations and backups panel crashed the whole admin when opened for Aster staging. Control-plane logs proved three ReturnsValidationError failures: native Convex pagination emits pageStatus and splitCursor, while operations.pageForInstance, operations.pageBackupsForInstance and fleet.history declared only page/isDone/continueCursor. Earlier in-memory tests did not return this native metadata.

All three now use Convex's official paginationResultValidator, retaining native page-split information needed by usePaginatedQuery. A regression invokes the actual history handlers and checks the real runtime result shape against each exported return contract. It failed on both missing fields before the repair and now passes. Nine fleet tests / 53 assertions, control-plane TypeScript and Admin web TypeScript passed. The Lifecycle panel also has a scoped error boundary with retry and close controls so a history outage cannot unmount the surrounding site admin; closing the panel unmounts its subscriptions.

Deployed the repaired control plane with TypeScript enabled, reopened the native panel, saved a staging-only five-minute health policy (backups and retention disabled), and created a full manual staging backup through the native button.
