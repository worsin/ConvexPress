# Post duplication repair — 2026-09-05

The existing `posts.mutations.duplicate` handler copied only article text/excerpt/image while dropping the block tree, content mode, section composer, structured content and presentation fields. It used public read permission on published documents, allowing an author to copy another author's protected full body into an owned editable draft. It also reset visibility to public and copied the source publication-job metadata.

The repaired handler requires actual source editorial authority in addition to `post.duplicate`. It retains the complete legacy authoring snapshot, nested block layout/lock envelope, layout override and page prompt. It validates the catalog and disabled-block insertion policy. A new block copy starts at revision 1; article copies retain article mode. Copies are fresh drafts owned by the current editor, with distinct slugs and top-level page paths. Password/private visibility and direct, route, and homepage membership protection survive as separate policy groups. Source scheduling, autosaves, edit locks, publishing timestamps and imported external identity are not copied. Taxonomy assignments, ordinary post metadata and canonical custom-field values are retained; media-bearing writes use the shared attachment guards.

All related collections are preflighted before inserts using indexed iteration: at most 256 records per collection, 512 total and 2 MiB of measured source/copy input. Exceeding limits refuses atomically rather than silently truncating. This is an explicit atomic copy limit, not a resumable large-document implementation. The shared membership copy helper snapshots matching source route and homepage rules into independent document policy groups. It preserves alternatives within each group and requires every independent group, including on repeated duplication. Global route records remain unchanged, and destination route policy still applies. The group field survives the shared promotion schema, export/apply/retry and rollback; see duplicate-membership-policy-outcome.md.
