# Viewport-aware Section reveal

The opt-in SDK Section reveal previously started on mount. A section below the fold could therefore finish its animation before a visitor reached it. Section now observes viewport entry once and runs its existing500ms opacity/12px transform animation only when it intersects. It has no permanent layer hint, animated dimensions, per-frame React updates, filter animation or new framework dependency.

Server output and pending/unavailable-browser states remain fully visible. Initial or live reduced-motion preference renders static content, keyboard focus settles an active/pending reveal immediately, and subsequent intersections do not replay it. Observation disconnects after entry; preference/focus listeners are removed on unmount. No content is marked hidden or inert. The primitive gallery's actual interactive section opts in as an acceptance specimen. Canonical blocks are not globally forced to animate.
