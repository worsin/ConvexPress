# Control-plane authored promotion preview/review design

Add an independent reviewed-content broker. It will never call snapshot export/import, direct database/admin authentication, or site apply. The only remote steps are the existing signed siteBroker operator-session exchange, source public exportManifest, and target public dryRun. Requested sessions remain in action memory; tokens, controller credentials and source download URLs are neither returned nor persisted.

A bounded request identifies two active connected environments of the same active ConvexPress website, staging source and live target, distinct instance/deployment origins, compatible contract/schema versions, and explicit authored selection/media/dependency bindings. CP stored RBAC must grant source/target promotion and administration plus target live operation; site handlers independently validate real authoring capabilities, plugins, dependency maps and media hashes. This first transport is restricted to canonical paired Convex cloud/site origins, failing explicitly for unimplemented self-host transport.

Begin allocates an operator/request-key-bound durable CP receipt. Request and authority/connection identity hashes support retry and conflict checks; immutable request-key collisions fail. Reviewing receipts expire and cannot auto-replay indefinitely. Finalization re-resolves stored authorization and connection identity after remote calls, compares the exact source/target manifest identities, and stores the bounded authored manifest and sanitized review summary privately. Public responses expose identities, counts, validated authored record previews, changed fields, issues, hashes and media readiness; never raw private manifest/download URLs or session material. Site review receipt/digest is retained for a future separately authorized apply design, but canApply is always false and no apply endpoint exists.

Caller media bindings refer to existing target uploads; target dryRun verifies their bytes. Missing media yields actionable not-ready review issues; the broker does not upload or copy assets yet. Source/target content can change after review, so readiness expires and is not an apply guarantee. Transport failures persist a generic failure code without logging remote error bodies. Existing grants/runtime data and full-snapshot disablement remain intact.
