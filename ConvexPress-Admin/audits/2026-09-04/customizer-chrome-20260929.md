## Causes and repairs

**E65 — shared settings schema drift.** Website's standard modules included menuLayout and nested header/footer fields, but Admin maintained an incomplete copy. Pack synchronization did not copy this schema, so installed manifests silently lost controls in native Admin. The portable schema now lives in Website SDK `settingsSchema.ts`, with a byte-identical generated Admin mirror checked by the existing template tooling. Website CSS generation remains in its runtime module. A failing-before parity test now covers all four installed packs, nested defaults, menu locations and header layout fields.

**E66 — valid module ID refused.** Once menu locations were exposed, actual native Save draft failed with `Invalid module settings.` The backend used the lowercase pack-slug validator for module IDs, rejecting the installed SDK ID `menuLayout`. A separate module-ID validator accepts the existing camelCase vocabulary while preserving lowercase pack IDs and plain-object field validation. Registered-handler regression covers save/recovery/publish, unchanged publication during draft save, and refusal of malformed pack/module/field shapes. This one backend file was deployed only to disposable target 4870 from its previously sealed locale-promotion snapshot. Source 4860 was untouched. Fresh private backup includes storage; strict deployment type check passed; 1,609 source hashes sealed, zero generated drift, all 2,371 function signatures unchanged.

**E67 — footer editor overflow.** The toolbar expanded to 429px inside the narrow Customizer panel, and row controls used viewport breakpoints. The builder now wraps its toolbar, permits flex children to shrink, and uses its own named container for row/cell-picker columns. Native expanded controls fit a 316px builder, scrollWidth 316, with no control outside its bounds. Screenshots were inspected. The dashboard's existing Customize Your Site quick link also now opens `/appearance/customize` instead of General Settings (a previously documented E09 entry-point defect).
