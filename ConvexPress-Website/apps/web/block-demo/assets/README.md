# BlockDemo sample images

These ten generated sample images belong to the internal BlockDemo fixtures. They are synthetic demonstration assets, not customer uploads or production site media. Source copies were promoted from the local Aster House, community gallery and editorial design outputs so a source checkout can build BlockDemo without ignored output directories. The promotion preserved the original bytes; no resizing, recompression or visual editing occurred.

The build fingerprints and bundles referenced images. Production sites resolve their own authorized media records and do not use these fixture imports.
